## `👋` About Me

I’m interested in creating systems that are useful in the real world: reliable backend services, Discord applications, automation tools, audio workflows, and computer-vision experiments.

I care about more than getting something to work. I like understanding how it works, finding bottlenecks, improving the architecture, and making the result easier to maintain.

- 🔧 Building tools and applications with a practical purpose.

## `🧩` Engineering Principles

- **Keep it modular** — separate responsibilities and make components easier to replace.
- **Design for failure** — handle errors, reconnects, timeouts, and unexpected states.
- **Measure performance** — optimize based on evidence rather than assumptions.
- **Automate repetitive work** — spend more time building and less time repeating manual steps.
- **Prefer maintainability** — readable code and clear structure matter.
- **Keep learning** — test ideas, compare approaches, and improve continuously.
